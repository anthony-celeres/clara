# 05b — Content Review Worksheets (for the domain reviewer)

**You don't need any technical knowledge to use this.** Each table below is a list
of things CLARA currently tells citizens. Your job: check each one against the
actual law / agency rule, and mark whether it's right.

For every row, fill the last three columns:
- **Verdict** — `✓` correct · `✗` wrong · `~` partly right / needs nuance
- **Correction** — if `✗` or `~`, what it should say
- **Source + date** — the law/issuance you checked against, and the date you checked
  (fees and rules change, so the date matters)

A guide can only go live when **every row is ✓** (or a `✗` has been corrected and
re-checked) **and you sign the block at the end of its section.** You can sign off
one guide without the others.

> Pre-filled from the current guide content. If CLARA's wording has changed since,
> the coordinator will re-sync this before you start.
